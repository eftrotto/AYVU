# Créditos dos assets visuais do Macu

Os sprites de corpo inteiro usados no avatar "Macu" vêm do projeto [Universal LPC Spritesheet Character Generator](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator), que reúne arte da comunidade **Liberated Pixel Cup (LPC)** hospedada no OpenGameArt.org.

Licenças: **CC-BY-SA 3.0** e/ou **GPL 3.0** (conforme o arquivo). Isso exige, no mínimo, dar crédito aos autores originais ao redistribuir este projeto (mesmo modificado).
